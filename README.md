# Retail Sales Performance & Revenue Analytics Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze retail sales performance, revenue trends, profitability, regional sales, and product category performance.

## Technologies Used
- Power BI Service
- Power Query
- DAX
- Excel
- Data Modeling

## Key Features
- Revenue, Profit, Profit Margin, and Total Orders KPIs
- Monthly Revenue Trend
- Revenue by Region
- Revenue by Product Category
- Revenue by Sales Channel
- Interactive Region and Product Category filters

## Data Model
Created relationships between three tables:
- Sales
- Products
- Regions

## Key Metrics
- Total Revenue: $87.01K
- Total Profit: $49.62K
- Profit Margin: 57.04%
- Total Orders: 600

## Business Value
Provides an interactive overview of retail sales performance to help identify revenue trends, compare regions, evaluate product categories, and support data-driven business decisions.
